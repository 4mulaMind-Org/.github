## 📌 Featured Projects

### ⭐ 4mulaQuery — Custom Database Engine
[![Repo](https://img.shields.io/badge/Repo-4mulaQuery-181717?style=flat-square&logo=github)](https://github.com/4mulaMind-Org/4mulaQuery)
[![C++](https://img.shields.io/badge/C++-17-00599C?style=flat-square&logo=cplusplus)](https://isocpp.org)
[![Java](https://img.shields.io/badge/Java-17-ED8B00?style=flat-square&logo=openjdk)](https://openjdk.org)
[![Docker](https://img.shields.io/badge/Docker-Deployed-2496ED?style=flat-square&logo=docker)](https://docker.com)

A fully functional **relational database engine built from scratch in C++** — no existing DB library used. Implements **B+ Tree indexing** for O(log n) operations, **binary file storage**, page management, and a **Java Spring Boot REST API** bridge. Integrated an **ML anomaly-detection pipeline** (Python Isolation Forest) for slow-query detection and engine health scoring. Dockerized and live.

> 🔗 [Live Demo](https://fourmulaquery.onrender.com)

### ⭐ Provider Matrix — Distributed Lead Allocation
[![Repo](https://img.shields.io/badge/Repo-Provider--Matrix-181717?style=flat-square&logo=github)](https://github.com/4mulaMind-Org/ProviderMatrix)

Production-grade **distributed lead allocation platform** simulating a real marketplace under high concurrency. **ACID-compliant transactions** with PostgreSQL row-level locking (`FOR UPDATE`) to prevent race conditions, deterministic fair round-robin allocation, **idempotent webhook processing**, and real-time WebSocket monitoring.

### ⭐ Developer Productivity MVP
[![Repo](https://img.shields.io/badge/Repo-mvp-181717?style=flat-square&logo=github)](https://github.com/4mulaMind-Org/mvp)
[![React](https://img.shields.io/badge/React-18-61DAFB?style=flat-square&logo=react)](https://react.dev)

### 🏥 Hospital Management System
Full-stack dashboard for registering and managing patients, doctors, and appointments. **RESTful API with 15+ endpoints** (Node.js, zero external deps), full CRUD with JSON-file persistence, real-time search/filtering, one-click CSV export, and an integrated **AI chatbot assistant** for doctor search and appointment booking.

### 🌦️ Weather Forecast App
RESTful weather backend in **Java Spring Boot** with clean layered architecture (Controller, Service, DTO). External API responses modeled into dedicated DTOs for a stable API contract. Separate **HTML/CSS/JS frontend** consuming the backend to display live temperature, humidity, wind, sunrise/sunset, and forecasts.

### 🤖 WhatsApp Chatbot Backend
WhatsApp chatbot backend simulation with REST APIs for **webhook handling, logging, and health monitoring**. Automated context-aware reply handling with clean OOP architecture and **Docker deployment**.
